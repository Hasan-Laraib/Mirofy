# Security Policy

## Reporting a vulnerability

Report privately through this repository's GitHub private vulnerability
reporting. Do not open a public issue, and do not include working exploits,
credentials, or customer data.

We aim to acknowledge within 5 working days.

## Scope

In scope: the CLI, renderers, validators, and generated artifacts.
Out of scope: vulnerabilities in a diagram's own subject matter, and issues
requiring a compromised local machine.
