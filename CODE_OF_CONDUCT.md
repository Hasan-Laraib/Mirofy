# Code of Conduct

## The short version

Be straight with people, and assume they are being straight with you.

This project is about not overstating what you know. That habit is worth having
with people as well as with diagrams: say what you found, say what you are
unsure of, and let someone correct you without treating it as an attack.

## What is expected

- **Argue with the work, not the person.** "This benchmark measures the wrong
  thing" is useful. "You clearly did not think about this" is not, and it is
  usually wrong as well.
- **Say what you actually checked.** "I could not reproduce it on Node 18" is
  worth more than "works for me". A report that names its limits is easier to
  act on than one that sounds certain.
- **Take a correction well.** Being wrong in public is the ordinary cost of
  working in the open. Nobody here is keeping score.
- **Assume the boring explanation.** Most surprising behaviour is a bug, a
  stale cache, or a misread line — not indifference.

## What is not acceptable

Harassment, personal attacks, demeaning or discriminatory comments, publishing
anyone's private information, or sustained disruption of a discussion.

Do not use issues or pull requests to advertise unrelated products.

## Scope

This applies in every space this project uses — issues, pull requests, code
review, discussions, commit messages — and to public conduct elsewhere when
someone is representing the project.

## Reporting

Report to **lxh417bham@gmail.com**. Reports are read by the maintainer and kept
confidential. If a report concerns the maintainer, and you would rather not
send it there, GitHub's own abuse reporting is available and is outside this
project's control, which is the point.

## Enforcement

The maintainer will respond as the situation warrants: a private word, a public
correction, an edited or removed comment, or a ban. Anything beyond a private
word will be explained to the person concerned.

There is no committee here. This is a small project, and pretending otherwise
would set an expectation about response time that could not be met.
